# Тести для SvitloBot

Ці тести покривають основні сценарії роботи бота з графіками відключень світла.

## Встановлення

```bash
pip install -r requirements/test.txt
```

## Запуск тестів

```bash
# Всі тести
pytest src/tests/

# Конкретний файл
pytest src/tests/test_schedule_checker.py

# З детальним виводом
pytest src/tests/ -v

# З покриттям коду
pytest src/tests/ --cov=src/services/schedule_checker
```

## Покриті сценарії

### 1. Нормалізація графіків (`TestNormalizeSchedule`)
- ✅ Графік з відключеннями
- ✅ Скасований графік (порожній масив)
- ✅ Графік на кілька днів

### 2. Виявлення змін (`TestHasChanges`)
- ✅ Перший раз з'являється графік з відключеннями
- ✅ Перший раз порожній графік
- ✅ Зміни в часах відключень
- ✅ Скасування графіку
- ✅ Порожній масив `[]` від API
- ✅ З'явився графік на завтра
- ✅ Графік на завтра вже був показаний сьогодні

### 3. Викреслення минулих відключень (`TestIsShutdownPast`)
- ✅ Відключення ще не закінчилося
- ✅ Відключення вже закінчилося
- ✅ Відключення до півночі (00:00)

### 4. Повні сценарії (`TestCheckQueueScenarios`)
- ✅ Сценарій 1: Перший раз з'являється графік
- ✅ Сценарій 2: API повертає `[]`
- ✅ Сценарій 3: Графік скасовано
- ✅ Сценарій 4: Зміни в часах відключень

## Примітки

- Тести використовують моки для API та MongoDB, тому не потрібне реальне підключення
- Тести не перевіряють реальні повідомлення в Telegram (це робиться вручну)
- Для тестування повідомлень використовуйте реальний бот і перевіряйте вручну
